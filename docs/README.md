# Agentic workflow for adsorption energies and reaction pathways

- `adsorption-agent-workflow.md`: the full document for people (text, tables, equations, figure links).
- `agent-context.md`: the same content for agents, text only; every figure restated as a table, list or rule.
- `agent-writing-style.md`: how agents write and draw for this project.
- `CLAUDE.md`: when agents update which file.
- `figures/`: the 18 figures as PNG files, numbered in reading order.
- `figures/src/`: the Python (matplotlib) scripts that draw figures 13 to 18, plus `_style.py` with the shared look. Scripts for figures 1 to 12 are not in the repository.

Open the folder in any Markdown viewer (GitHub, VS Code, Obsidian, Typora) and the figures display inline. Equations use `$$ … $$` (LaTeX), which GitHub, VS Code and Obsidian render.
