# Repository survey: what to wrap, what to copy

Build on AtomisticSkills and wrap fairchem for CatTSunami's `AutoFrameDissociation`, AdsorbML's `DetectTrajAnomaly` and the UMA calculator, ACAT for the site graph and symmetry-unique pairs, ASE and Sella for bands, saddles, frequencies and IRC, MACE committees with uncertainty-toolbox for calibrated doubt, and CatBench for choosing the potential. Copy patterns rather than code: the `SKILL.md` format and type-hinted MCP tools from Anthropic's skills and the MCP Python SDK, hook-enforced checkpoints from the Claude Agent SDK, the locked `PROJECT.md` and verify stage from Get Physics Done, and the plan and replan log from TSAgent.

How this was checked: every repository below was opened on 21 October 2026 through the GitHub or GitLab API and its raw source files. Last activity is the date of the last push. Module and class names were read from source or README; anything not read is marked unverified. Step numbers follow the planner in `agent-context.md` sections 21 and 23: 1 retrieve, 2 sites, 3 placement, 4 initial configurations, 4.1 physics filter, 5 MLIP choice, 6 anomaly filter, 7 uncertainty, 8 rank and human pick, 9 final state with 9a to 9e, 10 atom mapping, 11 path search, 12 saddle validation, 13 DFT refinement, 14 report.

## What is missing from all of them

No repository chooses the nearest non-recombining final state on purpose, runs one gate on both endpoints with logged reasons, or calibrates its doubt; those three are ours.

- Minimum-distance final state. CatTSunami samples a fixed number of placements in a radial shell and keeps survivors; NEBscape seeks the global minimum, which may be the far product; Pynta enumerates symmetry-unique placements without ordering them by distance. ACAT's site graph makes our objective computable; nobody has written it.
- One gate on both endpoints. `DetectTrajAnomaly` catches recombination through its connectivity test, but it treats A* + B* as one adsorbate, so B can desorb while A stays and the frame passes. It has no moved-site, imaginary-mode or periodic-image check. The AdsorbML recipe stores the anomaly names per frame and drops those frames from the ranking; it keeps no rejection log with the distance, threshold and site behind each verdict.
- Calibrated doubt. MACE committees give variances and uncertainty-toolbox gives calibration metrics, but no repository joins them for adsorption or barriers. AtomisticSkills warns that energy spread across model families is invalid unless references match, so cross-family checks must use E_ads, not total energies.
- Periodic saddle validation as code. AtomisticSkills' TS and IRC skills exclude periodic systems and its NEB skill checks neither frequencies nor connectivity. TSAgent checks the imaginary mode but runs no IRC. Pynta runs IRC on slabs but is GPL and bound to Fireworks. No tool checks that the band connects the intended reaction, the main failure TSBench reports.
- A scientific decision trace. TSAgent logs plans, CatMaster keeps a research graph, AiiDA keeps calculation provenance. None records why a site pair or final state was chosen and which candidates were rejected.
- The endpoint-to-barrier measurement. No repository reports how the choice of final state moves the barrier, the DFT force calls or the band failure rate.

## Facts that change our documents

- NEBscape code is public under MIT on [MPCDF GitLab](https://gitlab.mpcdf.mpg.de/hjung/nebscape), with a [ChemRxiv preprint](https://doi.org/10.26434/chemrxiv.15002133/v1) linked from its README; the preprint was not opened here.
- AtomisticSkills' public adsorption baseline is `mat-surface-adsorption`, which calls MatCalc's `AdsorptionCalc` and so pymatgen's `AdsorbateSiteFinder`; the `mat-htvs-*` skills in `agent-context.md` section 13 are not public.
- AtomisticSkills already ships `ml-committee-uncertainty`, `chem-neb-barrier`, `chem-ts-optimization`, `chem-irc-verification` and `general-peer-review`; section 13's "not described" entries for TS search should point there, noting the molecular-only scope.
- fairchem v2 removed `OCPNEB`; CatTSunami now pairs `AutoFrameDissociation` with `ase.mep.DyNEB` and `FAIRChemCalculator`.
- `AdsorbateSiteFinder` now lives in `pymatgen.core.adsorption` inside pymatgen-core.

## Licence and access

- ASE, ACAT and Sella are LGPL, so importing them keeps an MIT release possible. CatKit, Pynta, arkimede and CatMAP are GPL-3.0: copy their ideas, not their code.
- TSAgent and Adsorb-Agent state no licence, so their code cannot be reused.
- UMA weights need a Hugging Face account and acceptance of the FAIR Chemistry License; TSAgent and atomate2 VASP runs need a VASP licence.

## Recommended stack

1. Host: AtomisticSkills as a Claude Code plugin; ours as one skill folder plus one MCP server on the MCP Python SDK.
2. Sites, pairs and site graph: ACAT `SlabAdsorptionSites` and `SystematicPatternGenerator`, symmetry operations from spglib; MatCalc and pymatgen as the baseline.
3. Final states: CatTSunami `AutoFrameDissociation` helpers for unwrapping and frames, with our nearest-first selection in place of its sampling.
4. Potential and band: UMA through `FAIRChemCalculator`, `ase.mep.DyNEB` with climbing image, then `sella.Sella` and `sella.IRC`.
5. Gate: `DetectTrajAnomaly` plus our per-fragment desorption, moved-site and imaginary-mode checks via `ase.vibrations`; CatBench's anomaly classes name each rejection.
6. Doubt: MACE committee via `ml-committee-uncertainty`, CHGNet as a cross-family check on E_ads, calibration with uncertainty-toolbox against DFT labels.
7. Potential choice: CatBench plus `ml-mlip-benchmark`; atom mapping from NEBscape.
8. DFT: atomate2 through the AtomisticSkills MCP server, custodian handlers before any LLM diagnosis; arkimede as the model for MLP-then-DFT refinement.
9. Agent patterns: `SKILL.md` format, hooks for checkpoints, `PROJECT.md` lock and verify stage, TSAgent-style plan and replan log, Pydantic models for cards and verdicts.
10. Evaluation: with-and-without scoring on OC20NEB tasks, as AtomisticSkillsBenchmark does.
